# Responsive Landing Page — NovaTech

## Project Description
This project is a modern, responsive landing page for a fictional technology brand called NovaTech. It was created using HTML5 and CSS3 to demonstrate semantic structure, responsive design, layout systems, and clean UI styling without JavaScript frameworks or external CSS libraries.

## Features
- Responsive navigation
- Hero section with call-to-action buttons
- Feature cards with hover effects
- About section with business-focused messaging
- Responsive footer with quick links and social links
- Mobile, tablet, and desktop support

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Concepts Demonstrated
- Semantic HTML
- Responsive Web Design
- Flexbox
- CSS Grid
- Media Queries
- CSS Box Model
- CSS Positioning

## How to Run
1. Open the project in VS Code.
2. Install the Live Server extension if it is not already installed.
3. Open the `index.html` file.
4. Right-click the file and select **Open with Live Server**.
5. The landing page will open in your default browser.

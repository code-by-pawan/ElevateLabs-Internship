# TaskFlow — To-Do List App

## Description
TaskFlow is a front-end to-do list application built using HTML, CSS, and vanilla JavaScript. It helps users stay organized by adding tasks, marking them complete, deleting them, and tracking what remains.

## Features
- Add tasks
- Mark tasks as complete or incomplete
- Delete tasks
- Dynamic task counter
- Empty state message when no tasks exist
- Enter key support for quick task creation
- Responsive design for desktop and mobile devices
- Instant UI updates without page reload

## Technologies

- DOM Manipulation
- Event Listeners

## How to Run
1. Open the project in VS Code.
2. Install the Live Server extension.
3. Open the `index.html` file.
4. Right-click the file.
5. Select **Open with Live Server**.
6. Test the application in Chrome.
